## 주요 기능

- `ACTION`으로 **실행할 API 동작**을 선택합니다.
- `PARAMS`로 **API 입력값**을 전달합니다.
- `EXPECT`로 **실제 출력과 기대값**을 비교합니다.
- 정확한 결과를 미리 알 수 없으면 조건 표현식으로 **출력의 길이, 범위 또는 내용**을 검증합니다.
- `ARTIFACTS`로 출력을 저장하고 `{{ out.alias }}`로 **이후 ACTION에서 재사용**합니다.
- Byte Array 입력은 일반 문자열과 구분되는 **배열 형식**으로 작성할 수 있습니다.

## 기본 흐름

1. **Test Case를 선택**합니다.
2. `ACTS`의 ACTION을 **순서대로 실행**합니다.
3. `PARAMS`를 **실제 API 입력으로 변환**합니다.
4. API 실행 결과를 **`EXPECT`로 검증**합니다.
5. `ARTIFACTS`에 지정한 출력은 **이후 ACTION에서 참조**할 수 있습니다.
